## 章节提取指引（给 skill 看）

生成 customization.md 时，按以下优先级提取各章节内容：

| 章节 | 提取来源 | 提取方法 |
|------|---------|---------|
| 一、项目类型 | pom.xml / build.gradle / 项目结构 | 从依赖和模块结构推断 |
| 二、核心技术栈 | pom.xml / build.gradle 依赖声明 | 提取 groupId:artifactId:version |
| 三、项目分层结构 | 包目录结构 + 类命名后缀 | 扫描 src/main/java 目录树 |
| 四、自定义开发规约 | 现有代码的命名模式、注入方式、工具类 | 统计多数用法作为规约 |
| 五、数据库规范 | DDL / Mapper XML / Entity 命名 | 提取表名和字段的命名模式 |
| 六、接口返回格式 | Controller 返回类型 + 全局异常处理器 | 找统一 Result/Response 类 |
| 七、异常体系 | 异常类继承树 + 全局异常处理器 | 扫描 extends Exception/RuntimeException |
| 八、日志规范 | 日志依赖 + 现有 log 调用模式 | 统计 log.info/error 的格式模式 |
| 九、业务特有要求 | 分布式锁用法 / 幂等实现 / 并发模式 | 扫描 Redis Lock / 唯一键 / synchronized |

**提取原则**：
- 以项目中**多数代码的实际做法**为准，少数偏离的视为历史债务
- 无法从代码推断的章节，标注「待补充」但**不省略章节**
- 每个规则尽量附带 1 个项目中的**实际代码示例**
