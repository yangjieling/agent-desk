# 日志与注释规范

> 本规则定义日志级别、内容、脱敏和注释的基线。示例以 Java 为主，其他语言按等价实践。
> 项目专属的日志框架 / 工具类（如 DongLogger）在项目级 `wiki/middleware/log4j2-guide.md` 中约定，本文件只讲通用原则。

---

## 1. 日志级别判定

| 级别 | 触发场景 | 典型例子 |
|------|---------|---------|
| ERROR | 系统故障，需要立即介入 | RPC 网络超时、DB 连接失败、未预期的 NPE / 反序列化异常 |
| WARN | 业务预期内的失败，或可恢复异常 | 库存不足、参数校验不过、幂等命中重复请求 |
| INFO | 关键业务节点、外部调用入参出参 | 订单创建入口、支付回调、跨系统调用前后 |
| DEBUG | 排障时才需要的详细信息 | 中间状态、循环内变量、耗时分段 |

**判定规则**：ERROR = 需要告警值班；WARN = 业务方能自己解决；INFO = 排障线索；DEBUG = 生产默认关闭。

## 2. 日志内容规范

- **结构化优先**：使用占位符 `{}`，禁止字符串拼接（性能 + 可解析）。
  - ✅ `log.info("创建订单 orderId={} userId={}", orderId, userId)`
  - ❌ `log.info("创建订单 orderId=" + orderId + " userId=" + userId)`
- **携带 traceId / requestId**：跨服务调用的日志必须能串起来（通常靠 MDC + 日志模板自动注入，业务代码不用手动加）。
- **大对象延迟求值**：JSON.toJSONString 类调用用 lambda 包一层，避免 DEBUG 关闭时仍产生开销。
  - ✅ `log.debug("payload=[{}]", () -> JSON.toJSONString(obj))`
- **禁止循环体内打日志**：会导致日志风暴、拖慢主流程。
  - 必须循环内记录时，在循环外聚合后单条输出（如 `失败 3 条, ids=[...]`）。
- **异常必带堆栈**：`log.error("xxx 失败", e)`（e 作为最后一个参数，不放占位符里）。

## 3. 敏感字段脱敏

日志中出现以下字段时必须脱敏，禁止明文：

| 字段类型 | 脱敏方式 |
|---------|---------|
| 密码 / Token / Secret / 证书 | 完全不打（不脱敏也不允许）|
| 身份证 | 保留前 6 + 后 4，中间 `****` |
| 手机号 | 保留前 3 + 后 4，中间 `****` |
| 银行卡 | 只保留末 4 位 |
| 邮箱 | 保留 `@` 前 3 位 + 域名 |
| 用户姓名 | 保留姓 + `**` |

项目应有统一脱敏工具类，编码时直接调用，禁止各处自己实现。

## 4. 注释：只写 WHY，不写 WHAT

**三类注释各有用途，其余场景一律不写：**

- **Javadoc**（公共 API / Service 方法）：一句话"做什么" + 关键约束（可空？幂等？副作用？）
- **段首注释**（方法内部分段）：单行概括本段做什么，用于长方法的视觉分段
- **行内注释**（复杂业务分支）：解释业务规则、历史决策、性能权衡——**这才是 WHY**

**反例（禁止）：**

```java
// ❌ 描述一目了然的代码
i++;  // i 加 1
if (list.isEmpty()) { ... }  // 判断列表是否为空

// ❌ 引用当前任务 / PR / 调用者（进 commit message，不进代码）
// 用于任务 T-1234 的新流程
// 供 OrderServiceImpl 调用

// ❌ 注释掉的代码（用 git 追溯，不留残骸）
// oldMethod();  // 2024-01 停用

// ❌ 空洞的 TODO
// TODO: 后续优化
```

**正例：**

```java
// ✅ 解释业务规则
// 秒杀场景冲突率 >30%,乐观锁重试代价过大,改用悲观锁
lock.lock();

// ✅ 解释历史决策
// 兼容 v1 客户端: v1 传的是 orderCode 不是 orderId,先按 code 查一次
if (v1Client) { ... }

// ✅ 解释性能权衡
// 单次批量最多 500 条: 超过后 ES scroll 上下文会超时
List<Doc> batch = docs.subList(0, Math.min(500, docs.size()));
```
